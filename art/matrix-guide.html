矩阵如何解魔方

不需要把 54 个色块当作 54 个独立变量。它们被约束在置换群中：每个转动只是一个 0/1 矩阵。把这条乘法链找出来，魔方就复原了。

01 / STATE

54 维状态向量

六个面按 U R F D L B 展开，每个色块是一个分量。颜色只是分量的取值。

x = [ U1 … U9 | R1 … R9 | … | B9 ]T
SIX 3×3 SLICES
x ∈ {U,R,F,D,L,B}54

六个 3×3 面矩阵只是同一个 54 维向量的切片。交换两行或重排索引，不会改变这个模型。

02 / TURN

54×54 置换矩阵

一次面转动 = 一次线性变换。矩阵中每行每列恰好一个 1，其余全是 0。

x′ = Pm · x
  • 正交：PTP = I，长度与颜色数守恒。
  • 稀疏：一次面转动只置换 20 个色块。
  • 可逆：P−1 = PT，逆转动就是转置矩阵。
03 / SOLVE

找到矩阵的乘积

Kociemba 两阶段搜索把解拆成 G1 前后的两段，再用矩阵乘法逐步验证。

Pmk ⋯ Pm1 · x0 = xsolved
PHASE 1 · 进入 G19 步
PHASE 2 · 受限转动13 步

状态用矩阵表示，转动用矩阵表示，求解就是搜索矩阵乘积。每一步都能被重新乘一遍验证。
